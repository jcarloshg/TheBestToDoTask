---
name: run-tests
description: Run Jest tests with different options (all, watch, coverage, single file)
---

## What I do
- `npm test` - Run all tests
- `npm run test:watch` - Run tests in watch mode
- `npm run test:coverage` - Generate coverage report
- `npm test -- <filename>` - Run single test file by name

## When to use me
Use this when you need to run tests during development or CI.
